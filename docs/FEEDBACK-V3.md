# moov. 추가 피드백 반영 (2026-11-23)

대상: https://moov-mirae-online-dev.jj04020985.chatgpt.site

## 구현
- 경기 찾기: 전체·풋살·축구 / 농구·러닝·더보기. 더보기에서 헬스·탁구·테니스·수영·배드민턴 선택.
- 모집하기: 풋살·축구·농구 / 러닝·헬스·더보기. 추가 4종목 선택.
- 추가 종목을 선택하면 여섯 번째 버튼에 선택 종목과 선택 색상 표시. 직접 종목 입력은 지원하지 않음.
- 친선경기는 기존 축구·풋살·농구 및 대표자 권한 유지.
- 교내 4개 장소와 직접 입력 지원. 장소 이름 필수, 주소·HTTPS 지도 링크·만나는 위치 선택. 상세에서만 추가 장소 정보 노출. 서버에서 길이와 링크 스킴 검증.
- 활동 모드 중복 버튼 줄 제거, 현재 모드 배지 18px/굵게/라임 강조. 실제 모드 전환과 팀 설정 버튼 유지.
- 내 활동 서버 페이지네이션: 최근 경기 일시 내림차순, 동일 시각은 ID로 정렬. 최초 10건, 다음 10건을 커서로 조회. 내가 모집/내가 신청 및 상태 필터를 서버에서 처리.
- 첫 데이터 조회에서 과거 전체 모집/신청/출석 명단을 가져오지 않음. 지난 날짜의 경기 찾기는 해당 날짜만 추가 조회. 과거 경기 상세 링크도 별도 조회로 유지.
- 마이페이지 전체 모집 건수는 DB 집계값으로 유지.
- Firebase 중복 이메일 오류 처리 및 UID 기본키 기반 프로필 갱신 유지. 동시 저장 시 한 UID에 한 프로필이며 요청 본문의 타인 ID를 신뢰하지 않음을 테스트.
- HTML HTTP 응답에 CSP frame-ancestors 'self' https://chatgpt.com 적용. 임의 사이트와 다른 chatgpt.site 테넌트의 iframe 삽입 제한. 서버 보안 정책 변경도 PWA 캐시 버전에 반영.

기존 22개 테이블 구조 및 기존 마이그레이션 변경 없음. 새 테이블, 데이터 이전, 기존 기록 삭제 없음.
소스 v6 ZIP, 비채팅 20개 테이블 69개 행의 비공개 로컬 백업 완료. 격리된 로컬 D1에 복원해 모든 행의 내용 해시 일치 확인.
일시적인 채팅 원문과 공지 원문은 삭제 정책을 위해 백업에서 제외. 기존 종료/시작/취소 시 채팅 삭제 로직과 트리거는 유지.
Firebase 프로젝트/인증 계정/로그인 유지 설정은 수정하지 않음. 공개 시연 사이트와 GitHub 저장소도 변경하지 않음.
분 단위 외부 스케줄러나 유료 서비스는 추가하지 않음.

## 검증 범위의 한계
실제 학교 이메일로 새 계정을 만들거나 실제 가입 메일 발송/중복 가입을 재시험하지 않았음. 기존 Firebase 구현과 로컬 인증 테스트로 확인.
사용자가 이미 확인한 모바일 자동 로그인은 별도 재검증하지 않음.
iOS/Android 실기기의 설치·업데이트 및 ChatGPT Sites 편집 화면의 모든 임베드 경로는 실제 검증하지 않았음. 허용한 임베드 출처는 동일 출처와 https://chatgpt.com이며 필요 시 실제 부모 출처를 확인해 최소 범위로 조정.
페이지네이션은 과거 목록 전송량을 줄이는 변경이며 DB 전체 읽기량이나 무료 요금 한도를 보장하지 않음. 신고·매너 이력은 기존 정책대로 보존.
