# moov. 버전 9 — 공동 개발 기준

2026-11-24 온라인 개발 사이트에 배포된 전체 코드를 반영했다. 소스 출처는 [SOURCE-PROVENANCE.md](SOURCE-PROVENANCE.md)에 기록한다. 이전 버전 문서와 현재 코드가 다른 경우 이 문서와 서버 정책을 우선 확인한다.

## 포함된 변경

- 경기 실제 시작 후 최대 3시간에 종료한다. 예정 종료가 더 빠르면 그 시각을 적용하고, 늦게 접속해도 기준 종료 시각을 저장한다. 자동 종료는 출석 인정이나 매너온도 지급을 뜻하지 않는다.
- 시작 날짜·시간을 변경하면 종료 일시도 기존 운동 시간을 유지하여 함께 변경된다. 새 모집글의 종료 시각은 시작 후 3시간 이내로 화면과 서버에서 검증한다. 기존에 길게 저장된 일정은 원본 기록을 보존하고 운영 종료 기준과 표시를 보정한다.
- 모집자 위임 후 동일 계정이 참가자 목록에 중복 표시되지 않는다. 조회 권한이 없는 참가자의 이름은 공개하지 않고 인원만 표시한다.
- 모집자와 확정 참가자의 텍스트 채팅, 모집자 공지, 채팅방 신고를 제공한다. 텍스트 500자, 방당 500개 제한, 최근 50개와 마지막 수신 이후 새 메시지만 조회한다.
- 채팅은 실제 시작 후 2시간 또는 경기 취소 시 종료한다. 수동 종료 버튼은 없다. 원문과 공지는 종료 시 삭제 대상이며 신고에는 대화 원문을 복사하지 않는다.
- 채팅은 활성 화면에서 3~15초 간격으로 조회하고 통신 오류 시 최대 30초 간격으로 재시도한다. 숨겨진 화면·오프라인에서 중단하며 연결 복귀 시 다시 받는다. 작성 중인 메시지를 주기 갱신 때문에 지우지 않는다.
- 경기 상세 10초, 경기 찾기와 내 활동 15초, 과거 기록 60초 간격으로 현재 화면만 갱신한다. 필터와 펼친 기록 페이지를 유지하며 화면 전체를 새로고침하지 않는다.
- 내 활동은 예정·진행 경기와 종료 후 24시간 이내 활동을 표시한다. 내가 모집한 경기는 내가 모집 탭으로 구분한다. 지난 기록은 마이페이지의 운동한 기록에서 신청/모집 탭과 10건 단위 추가 조회로 확인한다.
- 마이페이지 홈 화면 추가 안내에 앱 업데이트 버튼을 제공한다. 최신 문서를 먼저 읽고 통신 실패 시 앱 캐시를 이용한다. 경기 API와 채팅은 캐시하지 않는다.
- 채팅 입력 영역 확대, 알림 내역 전체 삭제, 운동 종목 더보기, 장소 직접 입력, 활동 모드 배지 개선, 클릭재킹 방어 응답 헤더를 포함한다.

## 시간 처리의 한계

현재 외부 스케줄러와 WebSocket 서버는 사용하지 않는다. 자동 반영은 열린 화면에서 주기적으로 서버를 조회하는 방식이다. 아무도 접속하지 않으면 경기 종료나 시간 경과에 따른 채팅 원문 정리는 다음 관련 서버 요청에서 수행한다. 실제로 사용자 접속과 관계없이 정각에 실행된다고 설명하지 않는다. 준비 코드 `tools/lifecycle-scheduler`는 비활성 상태로 보존하며 임의로 배포하지 않는다.

## 팀원 실행

기존 작업을 보존하고 최신 main을 가져온 뒤 다음 명령으로 확인한다. Node.js 환경 선택은 [공동 개발 안내](TEAM-DEVELOPMENT.md)를 따른다.

```sh
npm ci
npm run verify
npm run dev:demo
```

검증 앱은 로컬 임시 DB와 테스트 계정을 사용하며 실제 회원 데이터에 연결되지 않는다. `dev:demo`의 공개 배포는 하지 않는다. 실제 사이트 배포, 실제 D1 변경, Firebase 설정 변경은 GitHub 코드 업데이트와 별도의 작업이다.

## 검증과 DB 변경

- 버전 9의 TypeScript 검사, 빌드, 자동 테스트 68건 통과.
- 두 로컬 계정의 자동 채팅 수신과 입력 유지, 모바일 날짜 입력, 활동 필터 유지 확인.
- 실제 온라인의 문제 경기 종료와 인원 보존 확인.
- `0005`는 채팅 테이블/인덱스, `0006`은 알림 삭제 상태와 채팅 종료 트리거 변경이다. `0000`~`0006` 누적 마이그레이션을 포함한다. 이미 적용된 마이그레이션을 수정하거나 기존 DB를 초기화하지 않는다.
- 서로 다른 실제 스마트폰, PWA 설치 상태, 네트워크 복귀에 따른 지연은 추가 실기기 검증 대상이다.

개인정보, Firebase 로그인 상태, 실제 DB 백업, 서버 비밀키는 이 저장소에 포함하지 않는다.
